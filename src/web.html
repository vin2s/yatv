YATV

Телевизоры

Список ТВ: имя, другие имена голосом, адрес и приложение для поиска фильма. «найди фильм X» ищет в приложении первого ТВ; «… на втором этаже» — на нужном.

Фразы

Кроме «найди фильм X», YATV берёт только эти фразы. Для каждой — приложение и ТВ (по умолчанию — первый в списке). Пример: «free tv» → открыть Free TV на первом этаже; «free tv на втором этаже» → на втором.

Планы

Голосом: «добавь задачу сдать отчёт завтра до 18:00», «какие у меня сегодня планы», «что мне нужно сделать», «что дальше», «отметь выполненной …». Фразы «напомни…» остаются штатной Алисе — её напоминания приходят на все колонки сразу. Остальные фразы — тоже Алисе.

      Утренняя сводка

      «Алиса, доброе утро» — колонка перехватывает фразу и рассказывает: новости из вашего источника, погоду, планы на день, затем включает вашу волну. Остальные фразы остаются Алисе.

      «Доброе утро» по умолчанию остаётся Алисе. Напишите свою фразу — только она будет запускать сводку: новости, погода и планы на день. Можно несколько вариантов через запятую: «новости, включи новости». Скажите «стоп», чтобы прервать чтение.
