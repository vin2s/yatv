# История версий YATV

## 0.2.8 — Озвучка выбранного дня и «Сказать фразу вслух»
- «Обновить и прочитать вслух» читает выбранный день в календаре, а не всегда сегодня (в списке — активный вид: сегодня/завтра/неделя). Команда `syncspeak` принимает смещение дня; добавлен общий разбор `parse_ask`.
- Вкладка «Тест»: «Сказать фразу вслух» — вводишь фразу, колонка говорит её голосом Алисы и показывает, кто обработал (YATV/Алиса), маршрут и кому отдана (`POST /api/debug/say`).

## 0.2.7 — Отладка фраз и исправление повторов
- Исправлено дублирование распознанных фраз: intermediate-кадр от maind (text в field 1 отличается от запроса в field 2) больше не попадает в обработчик. Планы и другие фразы не повторяются дважды.
- Кнопка в «Планах» переименована в «Обновить и прочитать вслух»: обновляет календарь Google и сразу озвучивает выбранный вид (сегодня/завтра/неделя).
- Новая вкладка «Тест»: в неё перенесены журнал, «Перенос настроек» и «Обновление YATV» + «Отладка фраз» — сухой прогон показывает, кто обработает фразу: YATV (планы/сводка/ТВ/настроенная фраза) или штатная Алиса, без отмены Алисы и запуска сводки (`POST /api/debug/phrase`).
- В панели «Обновление YATV» — установка релиза 0.2.7.

## 0.2.6 — Перенос настроек между колонками
- Экспорт/импорт полной конфигурации: телевизоры, голосовые фразы, планировщик, Google, настройки сводки и обновлений, задачи и кэш календаря.
- Панель: блок «Перенос настроек» — кнопка «Скачать конфиг» (`GET /api/export`) и загрузка файла (`POST /api/import`).
- Импорт проверяет формат `yatv-config` и принимает только известные файлы.
- Внимание: файл конфига содержит секреты Google — не публикуйте его.

## 0.2.5 — Исправление self-installer'а
- `install.sh` больше не вызывает init-скрипт внутри себя (убрана гонка/зацикливание с супервизором `run.sh`): копирует файлы, сохраняет backup, убивает демон, а новый поднимает супервизор.
- Версия бинарника приведена в соответствие с тегом релиза.

## 0.2.4 — Раскладка архива для self-install
- GitHub Actions упаковывает aarch64-архив с папкой `yatv/` (как и armv7), чтобы `install.sh` находился по фиксированному пути `yatv/install.sh`.

## 0.2.3 — Проверка цикла автообновления
- Тестовый релиз для проверки полного цикла: проверка версии → скачивание → установка → перезапуск.

## 0.2.2 — Скачивание через api.github.com
- Архив скачивается через `api.github.com` с заголовком `Accept: application/octet-stream` (старый `wget`/CA на колонках не доверял сертификату `objects.githubusercontent.com`); добавлен фолбэк.

## 0.2.1 — Тест автообновления
- Тестовый релиз для проверки уведомления и автоустановки на всех колонках.

## 0.2.0 — Обновления из GitHub Releases
- `src/update.rs`: проверка последнего Release через `/releases/latest` (без лимита GitHub API), скачивание архива под архитектуру (`yatv-armv7.tar` / `yatv-aarch64.tar`), self-install с backup и откатом.
- GitHub Actions по тегу `v*` собирает оба архива и публикует Release.
- Панель: блок «Обновление YATV» — «Проверить», «Установить обновление», чекбокс «Обновляться автоматически» (фоновая проверка раз в 6 часов).
- Уведомление о новой версии приходит на все колонки; при включённом авто колонка ставит обновление сама.
