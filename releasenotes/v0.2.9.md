# YATV 0.2.9 — отладка в журнале и описание обновлений

- **Отладка во вкладке «Тест» теперь видна в журнале.** И «Отладка фраз», и «Сказать фразу вслух» записывают результат (фразу, кто обработал, маршрут) в общий журнал — можно смотреть историю проверок вместе с голосовыми фразами.
- **«Что изменилось» при обновлении.** Описание релиза подтягивается из GitHub API при проверке версии и показывается в блоке «Обновление YATV» — и когда доступна новая версия, и после установки. Раньше описание не отображалось, если проверка шла через быстрый redirect.

Обновление: вкладка «Тест» → «Обновление YATV» → «Установить обновление» (или автообновление).
