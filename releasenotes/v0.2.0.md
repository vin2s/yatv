## YATV 0.2.0 — Обновления из GitHub Releases

- `src/update.rs`: проверка последнего Release через `/releases/latest` (без лимита GitHub API), скачивание архива под архитектуру (`yatv-armv7.tar` / `yatv-aarch64.tar`), self-install с backup и откатом.
- GitHub Actions по тегу `v*` собирает оба архива и публикует Release.
- Панель: блок «Обновление YATV» — «Проверить», «Установить обновление», чекбокс «Обновляться автоматически» (фоновая проверка раз в 6 часов).
- Уведомление о новой версии приходит на все колонки; при включённом авто колонка ставит обновление сама.
