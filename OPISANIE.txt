YATV — автономный контроллер телевизора для Яндекс Станции

YATV — это собственная прошивка-надстройка для Яндекс Станции, которая превращает её в голосовой пульт и центр планирования. Программа работает прямо на колонке (ARMv7 и aarch64), имеет свой веб-интерфейс на отдельном порту 8766, свой ADB-ключ и интегрируется со штатной Алисой через локальный IPC.

ЧТО УМЕЕТ

1. Управление телевизором голосом
- «Алиса, найди фильм Колобок» — поиск фильма в приложении LazyMedia Deluxe на нужном телевизоре (ADB + ADBKeyBoard для кириллицы).
- «Алиса, включи Free TV» — открыть своё приложение на выбранном телевизоре.
- «на втором этаже», «внизу», «спальная» — голосом выбирается конкретный ТВ.
- Пульт в веб-панели: стрелки, ОК, назад, домой, громкость.
- Поддерживается несколько телевизоров: у каждого своё имя, алиасы и приложение для поиска.

2. Свои голосовые фразы
- В панели задаются свои фразы с привязкой к приложению и телевизору.
- YATV перехватывает только «свои» фразы — всё остальное (погода, музыка, умный дом) остаётся штатной Алисе.
- «Доброе утро» по умолчанию остаётся Алисе; фраза-триггер для сводки настраивается, можно несколько через запятую.

3. Планировщик и задачи
- Задачи и планы на день: «какие планы на сегодня / завтра / на неделю», «что дальше», «дедлайны».
- Русский разбор дат: «через 10 минут», «завтра в 9», «12 марта».
- Утренняя сводка и предупреждения о сроках.
- Вкладка «Планы»: список, календарь месяцем, редактирование задач, выполненные.
- Google Календарь и Google Задачи в обе стороны: чтение событий, добавление, отметка выполненных со своим OAuth-ключом.

4. Утренняя сводка
- По настраиваемой фразе («новости, включи новости») читает:
  - новости из RSS (РИА, РБК, Лента, Хабр, Коммерсантъ, ТАСС или своя ссылка), заголовок и детали, количество задаётся цифрой 1-10;
  - погоду из Open-Meteo или своего API (Яндекс.Погода, Гисметео и др. через ссылку);
  - планы на день.
- Порядок блоков меняется перетаскиванием, галки включают и выключают блоки.
- «Стоп» во время сводки прерывает чтение; без сводки «стоп» отдаётся Алисе, чтобы она штатно выключила музыку.

5. Веб-панель
- Вкладка «ТВ»: телевизоры, свои фразы, проверка фразы.
- Вкладка «Планы»: задачи, календарь, настройки планировщика, Google.
- Вкладка «Сводка»: источники, порядок блоков, число новостей.
- Темы «День / Ночь» с иконками солнца и луны, выбор запоминается.
- Общий журнал на 200 записей: голосовые фразы зелёным, ошибки и чужие фразы красным, разделитель даты.
- «Перенос настроек»: экспорт и импорт полной конфигурации (ТВ, фразы, планы, Google, задачи) на другую колонку.
- «Обновление YATV»: проверка GitHub Releases и установка с backup и откатом, автообновление.

6. Обновления
- Релизы на GitHub по тегу v*, две сборки: для ARMv7 и aarch64.
- Уведомление о новой версии приходит на все колонки, при включённом авто колонка обновляется сама.
- Установка сохраняет конфиг и откатывается при неудаче.

ПРИНЦИПЫ

- Автономность: программа работает на колонке, не требует постоянного компьютера.
- Свои ключи и токены пользователя; секреты не попадают в логи и репозиторий.
- Чужие фразы остаются Алисе — YATV берёт только то, что явно настроено.
- Совместимость: ARMv7 и aarch64 станции, в том числе со старым glibc.

ДЛЯ КОГО

Для тех, кто хочет использовать Яндекс Станцию как голосовой пульт к нескольким телевизорам и как ежедневный планировщик — со своими источниками новостей и погоды, своими фразами и полным контролем обновлений.
